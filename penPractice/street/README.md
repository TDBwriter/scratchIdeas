# Street Hand: graffiti-style writing for every day

**Status: e-ink edition built as front/back sheets (108 pages = 54 sheets), waiting for approval.** Built with the shared builder (`../hand/`): `node build.mjs`.

These are **writing styles, not slow art pieces.** Every letter is drawn fast, in about as many strokes as print. Each style is the Clear & Quick Print letters plus a few repeatable moves: squeeze, lean, corners, kicks, stretch, bounce and bubble.

| Style | `hand.mjs` | Moves | Used for |
|---|---|---|---|
| **Street caps** | `caps` | condensed, ~11° lean, curves → corners, a kick on the last stroke (not on T I J Y Q 1 4 7) | headings, labels, signs, notes |
| **Bounce** | `bounce` | everyday lowercase; letters hop the baseline, tilt and change size in a steady rhythm; ring dots | cards, notes, lists |
| **Handstyle** | `tag` | tag-style script: narrow, steep (~20°), very angular; stems start above the top line, tails and bars run long | your name, a signature, fast headings |
| **Throw-ups** | `throwUp` | one-line bubble letters round a print skeleton, overlapping left to right; optional quick fill | titles, names, covers — in seconds |
